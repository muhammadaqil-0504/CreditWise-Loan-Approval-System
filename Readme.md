# 💳 CreditWise – Loan Approval Prediction System

## 📌 Project Overview

CreditWise is a Machine Learning-based Loan Approval Prediction System that predicts whether a loan application should be approved or rejected based on applicant information.

This project implements an end-to-end Machine Learning pipeline using three classification algorithms: Logistic Regression, K-Nearest Neighbors (KNN), and Naive Bayes.

The main objective is to analyze applicant data, identify meaningful patterns, train classification models, and evaluate their performance for loan approval prediction.

## 🎯 Project Objectives

- Perform Exploratory Data Analysis (EDA).
- Understand relationships and patterns in loan applicant data.
- Handle missing values and preprocess the dataset.
- Encode categorical variables.
- Apply feature scaling.
- Train multiple Machine Learning classification models.
- Evaluate and compare model performance.
- Identify the best-performing model.

## 🤖 Machine Learning Algorithms

1. **Logistic Regression** – A supervised classification algorithm used to predict loan approval outcomes.
2. **K-Nearest Neighbors (KNN)** – A distance-based classification algorithm that predicts outcomes using neighboring data points.
3. **Naive Bayes** – A probabilistic classification algorithm based on Bayes' theorem.

## 📊 Exploratory Data Analysis (EDA)

The project includes:

- Dataset overview and statistical analysis.
- Missing value analysis.
- Data distribution and visualization.
- Correlation analysis.
- Identification of important patterns in loan applications.

## ⚙️ Data Preprocessing

- Handling missing values.
- Categorical feature encoding.
- Feature selection and preparation.
- Feature scaling.
- Train-test splitting.

## 📈 Model Evaluation

All three models are evaluated using the following performance metrics:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

Model performance is compared to understand which algorithm provides better classification results.
